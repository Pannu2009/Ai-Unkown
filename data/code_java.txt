Q: How do you do matrix math in Java?
A: Loops over float[]. Same as C.
void matvec(float[] W, float[] x, float[] y, int rows, int cols) {
    for (int r = 0; r < rows; r++) {
        float s = 0;
        for (int c = 0; c < cols; c++) s += W[r * cols + c] * x[c];
        y[r] = s;
    }
}

Q: How do you do softmax in Java?
A: Same math.
static void softmax(float[] x) {
    float mx = x[0];
    for (float v : x) mx = Math.max(mx, v);
    float s = 0;
    for (int i = 0; i < x.length; i++) { x[i] = (float) Math.exp(x[i] - mx); s += x[i]; }
    for (int i = 0; i < x.length; i++) x[i] /= s;
}

Q: How do you sample in Java?
A: Cumulative random.
static int sample(float[] p, Random r) {
    float x = r.nextFloat();
    for (int i = 0; i < p.length; i++) {
        x -= p[i];
        if (x <= 0) return i;
    }
    return p.length - 1;
}
