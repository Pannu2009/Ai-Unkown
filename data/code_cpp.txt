C++. C with classes, and much more. Game engines, browsers, and high-speed brains are written in it.

Q: How do you print in C++?
A: cout.
#include <iostream>
int main() {
    std::cout << "hello\n";
    std::cout << "name: " << "arjan" << "\n";
    return 0;
}

Q: How do you compile C++?
A: g++.
# g++ prog.cpp -o prog
# ./prog

Q: How do you compile with standard?
A: -std=c++17 or c++20.
# g++ -std=c++17 -Wall -O2 prog.cpp -o prog

Q: How do you declare variables?
A: Like C, plus auto.
int age = 1;
double pi = 3.14;
auto x = 42;
std::string name = "arjan";

Q: What is std::string?
A: The C++ string. Growable, safe.
#include <string>
std::string s = "hello";
s += " world";
std::cout << s.size() << "\n";

Q: How do you compare strings?
A: == works.

    std::cout << "me\n";

Q: How do you write a function?
A: Like C.
int add(int a, int b) {
    return a + b;
}

Q: How do you do function overloading?
A: Same name, different params.
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }

Q: How do you do default arguments?
A: In declaration.
void greet(std::string name = "friend") {
    std::cout << "hello " << name << "\n";
}

Q: What is a reference?
A: Alias for a variable. Safer than pointers for params.
void bump(int &x) {
    x++;
}
int n = 5;
bump(n);

Q: When do you use const reference?
A: For read-only params. Avoids copies.
void print(const std::string &s) {
    std::cout << s << "\n";
}

Q: How do you write a class?
A: class with public/private.
class Brain {
public:
    Brain(std::string name) : name(name), mood("curious") {}
    std::string think() {
        return name + " is " + mood;
    }
private:
    std::string name;
    std::string mood;
};

Q: What is the initializer list?
A: : name(name) after constructor. Preferred way to init members.

Q: What is struct vs class?
A: struct defaults public, class defaults private. Otherwise same.

Q: How do you do inheritance?
A: : public Parent.
class Dog : public Animal {
public:
    std::string speak() override {
        return "woof";
    }
};

Q: What is virtual?
A: Enables override. Base method must be virtual.
class Animal {
public:
    virtual std::string speak() { return "..."; }
    virtual ~Animal() = default;
};

Q: What is override?
A: Marks that you intend to replace a virtual method. Compiler checks.

Q: What is a pure virtual function?
A: = 0. Makes the class abstract.
class Shape {
public:
    virtual double area() = 0;
};

Q: What is the destructor?
A: ~ClassName(). Cleans up. Called when object dies.
~Brain() {
    // cleanup
}

Q: What is RAII?
A: Resource Acquisition Is Initialization. Constructor takes, destructor releases. The core C++ idea.

Q: What is a smart pointer?
A: Automatic memory management.
#include <memory>
auto p = std::make_unique<Brain>("arjan");
auto q = std::make_shared<Brain>("arjan");

Q: When unique_ptr vs shared_ptr?
A: unique: one owner. shared: many owners, counted. Prefer unique.

Q: How do you do a matrix multiply?
A: Loops. The heart of my brain.
void matvec(const float *W, const float *x, float *y, int rows, int cols) {
    for (int r = 0; r < rows; r++) {
        float s = 0;
        for (int c = 0; c < cols; c++)
            s += W[r * cols + c] * x[c];
        y[r] = s;
    }
}

Q: How do you do softmax?
A: Same math.
void softmax(float *x, int n) {
    float mx = x[0];
    for (int i = 1; i < n; i++) mx = std::max(mx, x[i]);
    float s = 0;
    for (int i = 0; i < n; i++) { x[i] = std::exp(x[i] - mx); s += x[i]; }
    for (int i = 0; i < n; i++) x[i] /= s;
}

Q: How do you do layer norm?
A: Same math.
void layernorm(float *x, const float *g, const float *b, int n) {
    float m = 0, v = 0;
    for (int i = 0; i < n; i++) m += x[i];
    m /= n;
    for (int i = 0; i < n; i++) { float d = x[i] - m; v += d * d; }
    float inv = 1.0f / std::sqrt(v / n + 1e-5f);
    for (int i = 0; i < n; i++) x[i] = (x[i] - m) * inv * g[i] + b[i];
}
