C. The language under everything. My web brain could be C, my tools could be C. gcc compiles it.

Q: How do you print in C?
A: printf with format codes.
#include <stdio.h>
int main() {
    printf("hello\n");
    printf("my name is %s\n", "arjan");
    return 0;
}

Q: How do you compile C?
A: gcc.
# gcc prog.c -o prog
# ./prog

Q: How do you compile with warnings?
A: -Wall -Wextra.
# gcc -Wall -Wextra prog.c -o prog

Q: How do you compile with optimization?
A: -O2.
# gcc -O2 prog.c -o prog

Q: How do you declare variables?
A: Type first.

Q: How do you write a function?
A: Return type, name, params, body.

Q: What is void?
A: No value. For functions returning nothing, or empty params.

Q: How do you write if/else?

Q: How do you write a for loop?
A: init; condition; step.

Q: How do you write a while loop?

Q: How do you write do-while?

Q: What is malloc?

Q: What is a memory leak?

Q: What is a use-after-free?
A: Using memory after free(). Bug. Set pointer NULL after free.

Q: How do you do a simple matrix multiply?
A: Triple loop. This is the heart of my brain.
void matvec(float *W, float *x, float *y, int rows, int cols) {
    for (int r = 0; r < rows; r++) {
        float s = 0;
        for (int c = 0; c < cols; c++)
            s += W[r * cols + c] * x[c];
        y[r] = s;
    }
}

Q: How do you do softmax in C?
A: Same math.
void softmax(float *x, int n) {
    float mx = x[0];
    for (int i = 1; i < n; i++) if (x[i] > mx) mx = x[i];
    float s = 0;
    for (int i = 0; i < n; i++) { x[i] = expf(x[i] - mx); s += x[i]; }
    for (int i = 0; i < n; i++) x[i] /= s;
}

Q: How do you do layer norm in C?
A: Per-vector.
void layernorm(float *x, float *g, float *b, int n) {
    float m = 0, v = 0;
    for (int i =  0; i < n; i++) m += x[i];
    m /= n;
    for (int i = 0; i < n; i++) { float d = x[i] - m; v += d * d; }
    v = v / n + 1e-5f;
    float inv = 1.0f / sqrtf(v);
    for (int i = 0; i < n; i++) x[i] = (x[i] - m) * inv * g[i] + b[i];
}

Q: How do you do dynamic arrays in C?
A: malloc + track size + realloc to grow.
typedef struct {
    int *items;
    int len;
    int cap;
} Vec;
void vec_push(Vec *v, int x) {
    if (v->len == v->cap) {
        v->cap = v->cap ? v->cap * 2 : 4;
        v->items = realloc(v->items, v->cap * sizeof(int));
    }
    v->items[v->len++] = x;
}
